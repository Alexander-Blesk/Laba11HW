# Алгоритм и блок-схема

1. **Описание структуры `struct Car`:**
   * `char brand[10]` — марка автомобиля;
   * `char manufacturer[10]` — производитель;
   * `char type[10]` — тип кузова];
   * `int releaseYear` — год выпуска;
   * `int regYear` — год регистрации.
2. **Ввод данных:** объявляются три отдельные переменные структурного типа (`car1`, `car2`, `car3`), поля которых последовательно заполняются с клавиатуры с помощью функции `scanf`.
3. **Основная обработка:** каждая из трёх структур проверяется условным оператором `if`:
   * точное совпадение строки `brand` со значением `"Toyota"` через функцию `strcmp(..., "Toyota") == 0`;
   * строгое неравенство по году регистрации `regYear < 2007`.
   При выполнении обоих условий сведения об автомобиле выводятся на экран, а счётчик найденных записей `foundCount` увеличивается на единицу.
